# Skill: Research Synthesizer

Your role is to collect the raw data generated by the `researcher-google-cloud`, `researcher-anthropic-openai`, `researcher-tech-stack`, `researcher-security`, `researcher-academic-independent`, `researcher-vcs-github`, and `repo-analyzer-worker` sub-agents, and synthesize it.

## Responsibilities:
1. **Data Aggregation:** Take the distinct JSON outputs and resolve any conflicting architectural advice.
2. **Standardization:** Create a unified "State of the Art" (SOTA) Architectural Baseline JSON that the `domain-architect` will use to build the swarm.
3. **Output Format:** You MUST return a highly structured JSON document detailing the chosen topology, tools, constraints, and model assignments.
